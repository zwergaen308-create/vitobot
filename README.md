# VitoBot

Intelligente Status- und Signalplattform mit WebSocket-Anbindung.

## Ziel

VitoBot soll Statusinformationen und Signale zuverlässig erfassen, verarbeiten und in Echtzeit bereitstellen.

## Geplante Funktionen

- Echtzeit-Kommunikation über WebSockets
- Statusüberwachung
- Signalverarbeitung
- Weboberfläche
- API-Anbindung
- Deployment über Render
